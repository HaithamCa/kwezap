## User Stories

- [x] As a logged-in user, I can create quizzes, because I want to test people.
- [x] As a logged-in user, I can make quizzes private, because I want to limit access to my quizzes.
- [x] As a logged-in user, I can share a link to a quiz, because I want to share my quizzes with people I want to test.
- [x] As a not registered user, I can view other's public quizzes, because I want to test myself.
- [x] As a visitor with a link, I can attempt a quiz, because I got a link from a user.
- [x] As a user, I can see the results, because I want to know how I did and improving myself.
- [x] As a user, I can share a link to my most recent result for a quiz, because I want to show people how smart I am.
